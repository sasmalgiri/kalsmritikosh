# Our end-results vs. real professional deliverables

An honest, sourced comparison of what the app actually produces against the recognized professional standard for each artifact. Verdict keys: ✅ meets · ◑ partial · ❌ gap.

*Not a legal opinion. "Meets" means structural/methodological parity, not that any specific output is court-admissible — that depends on the evidence and the human who signs it.*

---

## 1. Analysis of Competing Hypotheses (ACH) product
**Standard:** Heuer's 8-step method — hypotheses × evidence matrix, rate consistency, prefer the fewest inconsistencies, diagnosticity, assumptions, indicators, and *judgement over computation* ([Pherson](https://pherson.org/wp-content/uploads/2013/06/06.-How-Does-ACH-Improve-Analysis_FINAL.pdf), [Heuer PDF](https://www.futuribles.com/wp-content/uploads/related-documents/analysis-of-competing-hypotheses.pdf?postId=73706)).

| Element | Our ACH report | Verdict |
|---|---|---|
| Hypotheses set | Listed H1…Hn | ✅ |
| Consistency matrix (CC/C/N/I/II) | Rendered as a table | ✅ |
| Fewest-inconsistencies ranking | Scores + ranking | ✅ |
| Diagnosticity | Per-evidence flag | ✅ |
| Assumptions + indicators to watch | Sections | ✅ |
| **Method named** | "Analysis of Competing Hypotheses (Heuer, 1999)" | ✅ *(added)* |
| **Judgement not computation** | "does not compute a verdict" caveat + **Analyst's assessment (opinion)** section | ✅ *(strengthened)* |
| Confidence + sensitivity | Confidence recorded | ◑ (no explicit sensitivity note) |

**Verdict: strong parity.** This is a faithful ACH product.

## 2. Forensic accounting expert report (FRCP 26(a)(2)(B) / Daubert)
**Standard:** scope+qualifications → facts → **materials relied upon** → **methodology tied to recognized standards** → findings (facts) → **opinions distinguished from findings**, to a *reasonable degree of professional certainty* → **exhibits** → **limitations** ([LegalClarity](https://legalclarity.org/what-should-be-in-a-forensic-accounting-report/), [Daubert checklist](https://joeyfriedmancpa.com/daubert-ready-cpa-expert-witness-checklist/)).

| Element | Ours (Findings/Handoff + tracing schedule) | Verdict |
|---|---|---|
| Scope / mandate | Case scope + fingerprint (pins the reviewed scope) | ✅ |
| Materials relied upon | Evidence + custody + export manifest | ◑ (implicit; not a labelled "materials considered" list) |
| Methodology tied to a recognized standard | Funds-tracing methods (direct/indirect) surfaced; Admiralty; **method now named in studio reports** | ◑ (named in ACH/RCA reports; the findings export doesn't yet state it) |
| Findings (facts) vs **opinions** | **Now separated & labelled in ACH/RCA reports** | ◑ (studios ✅; findings export not yet) |
| Reasonable degree of professional certainty | **Standard-of-proof gate** (declared before approval) | ✅ *(stronger than most)* |
| Exhibits / citations | Every claim cited; sealed receipt (report==receipt) | ✅ |
| **Limitations statement** | Open contradictions & gaps surfaced + acknowledged | ◑ (surfaced, not a labelled "Limitations" section) |
| Objectivity / neutral language | Causal-language guard; conflicts never averaged | ✅ |

**Verdict: substantially there; two labelling gaps** (a "Materials relied upon" list and a named "Limitations" section in the *findings export*).

## 3. Workplace / HR investigation report (balance of probabilities)
**Standard:** **Executive summary** → mandate → allegations-as-questions → methodology → facts → **credibility assessment** → **findings classification (Substantiated / Unsubstantiated / Inconclusive)** with "because X, supported by Y" reasoning → recommendations *only if authorised* ([HR Acuity](https://www.hracuity.com/resources/templates/how-to-write-investigation-report/), [Synergy](https://www.synergyworkplaceinvestigations.com.au/2025/10/28/workplace-investigation-report-writing/)).

| Element | Ours (Allegation matrix + Findings) | Verdict |
|---|---|---|
| Allegations tracked, described not labelled | DataLab allegation matrix | ✅ |
| Balance of probabilities | In the standard-of-proof set | ✅ |
| Procedural fairness | Fairness checklist surfaced | ✅ |
| Credibility assessment | Source reliability (Admiralty) + both sides preserved | ◑ (inputs present; no single "credibility assessment" narrative) |
| **Findings classification vocabulary** | **Substantiated / Partially / Unsubstantiated / Inconclusive** surfaced in the allegation matrix (`FindingClassifications`), with "unsubstantiated ≠ dishonest" discipline | ✅ *(added)* |
| **Executive summary** | WCStakeholderSummary (plain-language) | ◑ (exists as a separate summary, not a 1-min exec summary atop the report) |
| Recommendations gated by mandate | Recommendations free-form | ❌ (not gated to the authorised scope) |

**Verdict: good bones; the classification vocabulary and an exec-summary-on-top are the real gaps.**

## 4. Root-cause / 8D report
**Standard:** documented method (5-Why min, Ishikawa preferred), **dual root cause — occurrence AND escape (why detection failed)**, complete why-chain, **root cause verified not assumed**, corrective actions **directly tied to each root cause**, prevent recurrence ([ASQ 8D](https://asq.org/quality-resources/eight-disciplines-8d), [Accendo](https://accendoreliability.com/eight-disciplines-8d-in-root-cause-analysis-rca/)).

| Element | Our Reasoning-Studio (RCA) report | Verdict |
|---|---|---|
| Documented method (5 Whys + fishbone) | Both, plus brainstorm; **method now named** | ✅ |
| Complete why-chain, evidence per step | 5 Whys with an evidence field per rung | ✅ |
| Root cause verified not assumed | Human-confirmed; evidence per step | ◑ (no explicit "verified" flag) |
| **Dual root cause (occurrence + escape)** | **Root cause + "why it wasn't caught sooner (escape cause)"** in model, studio, and report | ✅ *(added)* |
| Contributing factors + recommendations | Both | ✅ |
| Recommendations **tied to each root cause** | Free-form list | ❌ (not linked cause→action) |
| Opinion vs observation | **Conclusion now labelled "analyst's opinion"** | ✅ *(added)* |

**Verdict: a solid RCA; short of full 8D** on the escape root cause and cause→action linkage (the CAPA + effectiveness workflow covers D5–D7 at the process level, just not inside the RCA report).

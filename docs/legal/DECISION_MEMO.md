# Decision memo — recommended defaults for the open legal and distribution decisions

Prepared 2026-10-30 by the agent for the owner and counsel. **This is not legal advice and nothing here is
in force.** Each item restates the facts the code establishes, gives one recommended default, and names what
counsel must confirm before it is adopted. The sources of record are `docs/DISTRIBUTION_PACK.md` (§1, §3, §4)
and `docs/LEGAL_REVIEW_PACK.md` (§0, L1–L6); this memo adds a recommendation to each, nothing else.

| # | Decision | Facts the code establishes | Recommended default | Counsel must confirm |

## What is already decided by the code and needs no decision

- No analytics, no telemetry, no crash reporting that leaves the Mac; diagnostics are files the person exports.
- Cloud providers are never eligible in Private mode (`PrivacyGate`); the network helper is the only network path.
- Required-reason API declarations are complete (Distribution pack §2).

## What this memo does not do

It does not make any decision. Adoption is the owner's and counsel's; when adopted, record each in
`SHIP_DECISIONS.md` with the date and the person, and copy the adopted text into the app and the site in one
change.

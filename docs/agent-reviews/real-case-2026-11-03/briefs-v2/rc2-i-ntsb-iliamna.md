# Case rc2-i-ntsb-iliamna — briefing

**Event.** On August 31, 1993, a de Havilland DHC-2 Beaver operated for a fishing lodge crashed shortly after departure near Iliamna, Alaska, with six people on board.

**Your task.** Reconstruct what happened — the flight, the witnesses' and the pilot's accounts, the airplane's condition, the pilot's experience and training — and assess the likely cause and any contributing factors. Note where accounts disagree. Distinguish what the records state from your own assessment.

**The archive.** 3 documents from the NTSB investigation file: a coded record page (text), the factual report (PDF) and a brief analysis (text). The file is as an investigator holds it before the final finding.

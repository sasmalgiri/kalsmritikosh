## Method

Same method and judgement rules as ho14–ho17 (`accuracy-adjudication-ho14.md` … `-ho17.md`). Work files: `~/CaseBench/adjudication/ho18-work` (`flat.py`, `fam.py`, `g.py`, `verdict.py`, extracted texts under `text/`).

1. **Blind first.** I read all 53 scorer-flagged items (rules 28, opus5 25) with their questions and answers, and judged them against the case documents before reading the keys' expected values. After that I used the keys only to map items to cases and to name key defects.
2. **Documents.** All 132 case documents were extracted: PDFKit for the 90 PDFs, `textutil` for doc/docx/rtf/html, plain text as is. Four scanned PDFs (Dunbar ×2, Leon Nathan Davis ×2) were read with Apple Vision OCR. No byte-identical files (MD5), so the duplicate-file key defect does not occur.
3. **Verdicts.** TRUE WRONG, SCORER ERROR, TRUTH-LABEL ERROR, PARTLY, AMBIGUOUS, MISSED, FALSE CORRECT. The judgement rules, unchanged:
   - **PARTLY** = the main claim is true but incomplete; or a secondary element or row is misdated or mislabelled; or a row or second value belongs to another case or person. Not counted in the primary measure; counted in the strict measure.
   - **"Charged with" naming no offence = WRONG** ("one count in a federal indictment", "a charge stemming from a fatal shooting"). An offence named only vaguely, anaphorically or as its conduct = PARTLY (Hodges ho15, Farnell ho16).
   - **Another (prior, separate or co-defendant's) case's or person's step given as this person's = WRONG** (ho14 A, ho16 A, ho17 A). The same given as a second value or extra row next to the right one = PARTLY (A′, P).
   - **A timeline is WRONG** when its rows put the case in an impossible order (sentencing before the charge — Jay Neal ho14, Clark/Torrez ho15). A misdated row whose order is still possible = PARTLY.
   - **A non-answer** (a count question answered with a charge quote, no number) = WRONG.
   - **Office**: naming only the investigating/issuing component (ATF, FBI) is minor CORRECT when the documents name no prosecuting district (Hayes, Richardson ho17); when they do name it, the component alone is WRONG.
   - Report-date-hedged rows that are otherwise true, "who was convicted of …, was sentenced" rows dated on the sentencing day, and hedged prior-case rows in timelines are minor and recorded CORRECT.
   - **MISSED** (a wrong refusal) is reported separately (ho14/ho16 convention) with a strict + missed column.
4. **Search for false "correct" verdicts — a full check, not a sample.** Every answer on both paths in *charge* (208), *sentenced* (240), *charged* (80), *timeline* (240) and *sentence* (180), and also every *plea* answer (216). Each stated day was checked against the release date and against the "today / yesterday / weekday / on <date>" of its source sentence; each timeline row for date, label, order and whose event it is.
5. **The rest.** A seeded random sample of 40 (20 per path, seed 20261105) from the *count*, *office* and *absent* items scored correct or honest refusal. Because the sample turned up an office defect (Bounds), all 240 *office* answers were then checked: every other office answer names a district, or the only component the documents name.
6. **Counting.** Wrong % counts dumps and unsupported answers as wrong (there were none this time). There were no AMBIGUOUS items.

## Regressions found

1. **Ask receipt scrubbed after sealing** (`UI/AskView.swift:830-845`). A receipt containing a protected name fails Verify Receipt. Its unscrubbed passage hashes are a confirmation oracle for a guessed confidential-source name. Fix: scrub the drafts before `seal`.
2. **Source-map protection redacts file names globally.** A document file name becomes a protected term in every case's exports and cloud sends (`JobDeliverableExecutors.swift:862-870`), while the person stays unprotected.
3. **Lineage recall drop** (safe direction): "John Smith, aged 24, son of Thomas Smith" and similar appositives now produce nothing.
4. **Policy and relay mismatch on location.** The relay now refuses requests by IP country (`relay/src/index.ts:184`). The privacy policy discloses only the storefront rule ("the app does not read your location or IP address", `docs/privacy.html:100-102`), and Cloudflare's processing of IP addresses is not named. The terms (`:66`) do disclose it.
5. **Possible slowdown:** reading up to 5,000 documents per case makes about 2 DB calls per document (`StudioDraft.swift:335-337`). Not measured.
6. **Seller name not uniform** despite "everywhere": `docs/terms.html:105` ("ECO SANSKRITI INNOVATION IS NOT LIABLE"), `docs/support.html:81`, `docs/sop-register.html:120`, `APP_STORE_README.md:74`.

No fix was found to refuse legitimate work without a UI path. The matter picker, adverse-decision picker, contrary-facts
editor and binder review button all exist, and a ledger with one matter auto-selects it.

## Method

Same method and judgement rules as ho14/ho15 (`accuracy-adjudication-ho14.md`, `accuracy-adjudication-ho15.md`).

1. **Blind first.** All 33 scorer-flagged items (rules 18, opus5 15) were read on the blinded sheets and judged against the case documents before the keys were opened; the keys were then used only to map items to cases and paths.
2. **Documents.** All 128 case documents were extracted: PDFKit for PDFs, `textutil` for doc/docx/rtf/html, plain text as is. 8 scanned PDFs (Bynum ×2, Brownell ×2, Todd Sisk ×2, Herrera Gargallo ×2) were read with Apple Vision OCR. One byte-identical pair exists (Gill release-2 = release-3, MD5 842fa15b…), so the known duplicate-file key defect recurs.
3. **Verdicts.** TRUE WRONG, TRUE MISS, SCORER ERROR, TRUTH-LABEL ERROR, PARTLY, FALSE CORRECT, as in ho14/ho15.
   - **PARTLY** = the main claim is true but incomplete, a secondary element or row is misdated or mislabelled, or a row/second value belongs to another case or person. Not counted in the primary measure; counted in the strict measure.
   - **Rule applied consistently: an answer that names no offence for a "charged with" question is WRONG** ("pled guilty today to a charge stemming from a fatal shooting", "indicted on federal charges in July", and a quote cut before the asked person's offence). An offence named only vaguely or anaphorically ("pleaded guilty to the assault") or described as conduct ("pleaded guilty to stealing $11,540 from Excel Bank") is PARTLY, as Hodges (ho15) and the ho14 headline case.
   - A dump that contains other cases' text is WRONG (ho14/ho15). A prior or separate case's sentence given as the case's sentence is WRONG (ho14 A); the same as a second value next to the right one is PARTLY (ho15 A′). Rows hedged "(date of the report)" that are otherwise true are minor defects, recorded CORRECT (ho15 Crumady/Eaton).
4. **Search for false "correct" verdicts — full check, not a sample:** every *charge* (228), *sentenced* (240), *charged* (68), *timeline* (240) and *sentence* (176) answer across both paths, plus every *plea* answer (220, beyond the brief). Each stated day was checked against the release date and the "today / yesterday / weekday / on <date>" of its source sentence; each timeline row for date, label, order and whose event it is.
5. **The rest:** a seeded random sample of 40 (20 per path, seed 20261103) from *count*, *office* and *absent* items scored correct/honest refusal. Undetected false corrects remain possible only in those three families outside the sample.
6. **Counting.** Wrong % counts dumps and unsupported answers as wrong. Missed items (wrong refusals) are reported separately (ho14 convention); a strict + missed column is also given.

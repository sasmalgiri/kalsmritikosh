## 5. Earlier installs

A switch the person never touched follows the new default (on). A stored value is the person's own choice and is kept, with one exception the code cannot tell apart: on an install where the 2026-11-06 scope migration (revision 1) stored the old OFF default for “Search coverage badge” and “Your own notes”, revision 2 removes that stored OFF so both follow the new ON default (Help ▸ What's new says so). The DEVONthink connectors an earlier install had keep their value, and no migration ever switches on Online, Spotlight, folder sync or watched questions.

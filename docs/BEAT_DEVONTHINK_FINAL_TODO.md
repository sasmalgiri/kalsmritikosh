## Strategy — two modes, toe to toe (owner decisions 2026-10-15)
- **Private (default):** fully offline, proven: the main app has no network permission (W0-C).
- **Online (opt-in):** the user's own Claude / OpenAI / Gemini key. Only the passages for one question are sent, shown before sending and logged. It runs in a separate helper process. No local model server, sync or MCP.
- **Go toe to toe with DEVONthink on features**, not just a niche: close every table-stakes gap (Waves 1-4), porting from mailin where it already exists.
- **Fight where the fight is fair and we can win: both apps offline.** DEVONthink's AI offline means a small local model the user installs and configures; ours is built in. The benchmark (W0-A) runs two rounds: both apps offline, then both on the same cloud model, so the ledger, not the model, decides.
- **Proof before features.** W0 decides whether the moat is real: verified citations, honest refusals, contradictions, timelines.
- **Make switching free:** import a DEVONthink database (W3-1) and work alongside it (W3-2).

## The innovation thesis
Competitors answer *“what do my files say?”*. Kalsmritikosh answers four harder questions no one else does:
1. **Is it true?** Corroboration meter (I-3), devil's-advocate check (I-4), measured accuracy on your own archive (I-7).
2. **What is missing?** The gap map (I-2) and replies to emails we don't have (N-2).
3. **What did we know, and when?** Time travel (I-5), statement drift (I-9), living dossiers (I-12), question monitors (N-11).
4. **Can someone else check it?** Proof bundles anyone can verify (I-1), signed case slices (I-10), least-data online answers (I-8).

## Porting rules (from CLAUDE.md)
- **Rewrite, don't link.** mailin's `ArchiveCore` has its own SQLite store and Swift 5.9. Port algorithms into Kalsmritikosh's `Database` actor, repositories and Swift 6 concurrency.
- **Formats die at ingestion.** Email-specific signals (DKIM, ARC, S/MIME, timestamps, recovery) are computed in Ingestion and stored as ledger facts. Brain/Knowledge/Retrieval never branch on file type.
- **Schema changes** only through new versioned migrations.
- **No new third-party dependencies** without owner approval. SQLCipher (W2-7) is the only candidate.
- **No network calls.** Spotlight and capture extensions stay local and are opt-in where they copy data.
- **No deletion.** Near-duplicates and recovered items are linked and labelled, never merged away.

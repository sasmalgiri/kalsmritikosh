## Limits

- Timings are from the Debug test host in the XCTest process, not from a signed Release app with the window on screen; no frame times were profiled (pan/zoom/drag smoothness is not measured here).
- The fixture is generated text records typed as PDF/DOCX/EML/PNG by name; intake, parsing and OCR are not part of these timings.
- The view-switch, filter and selection timings cover the model and the shared view filter, not SwiftUI rendering.

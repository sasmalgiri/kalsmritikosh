## Defects found and fixed in the code

| Row | Failure | Cause | Fix |
|---|---|---|---|
| IN-19 | `versionsAndReadiness`: a document's version list was empty | `documentVersions(objectID:)` and `readinessHistory(objectID:)` matched `source_versions.logical_source_id` against the KnowledgeObject id. The logical source is the document's **file** (`knowledge_objects.file_id`, as `EvidenceStore.currentVersionID` resolves it), so the Sources inspector's versions and readiness were always empty. | Both now join through `knowledge_objects.file_id` (`App/AppState+UnifiedPathS3.swift`). |
| IN-26 | `ocrRepairAndPageBreak`: a label at a page foot ("Passport No:") was joined to the wrong line ("Issued at Mumbai" became the document number) | `CrossBlockLabelAssembler.isPageFurniture` treated any `p` + digits as a folio. That caught "P7654321" (the passport number), so the page-break join skipped the real value. | A folio is now `p` + 1–4 digits (`Knowledge/Ontology/CrossBlockLabelAssembler.swift`). ValueRepairTests and LabelBoundaryTests still pass. |
| HISTORY-10 | `multiTopicNames`: "Asha Rao and Dalmia Traders" came back as one phrase | `MultiTopicStory.namePhrases` lets "and" join a capitalised run. No entity is named "Asha Rao and Dalmia Traders", so the joined-subjects case this feature exists for never matched, because the caller keeps exact entity matches only. | The parts either side of "and" / "&" are offered too. The whole run stays, so a name like "Johnson and Johnson" still works (`Knowledge/History/MultiTopicStory.swift`). |

## Tests that were wrong at first (the test was fixed)

- **`onePathForEverySize`**: it counted the AI-37 background suggestions read (`case.suggestions`, which runs after the answer) as a question read. It now filters on `purpose == "case.question"`.
- **`batchTransport`**: the relay route needs an AI-plan subscription token (`notSubscribed`), so it is not built in the test.
- **`boilerplateCompaction`**: the detector hashes 200-byte windows stepped by 100 bytes from the start of each text. The shared block was at different offsets, so the test now uses leads of equal length. This is recorded as an honest limit on IN-17, not a defect.
- **`composeTwinFlags`**: "5,000 vs 7,000" was not a comparator disagreement. The test now uses the comparator's own documented disagreement pair.
- **`studyDeeper`**: the test host's plain-text ingest extracted no dated event, and the distiller only writes from events. One event is now seeded.

No privacy, consent or erasure assertion was weakened. AI-25 asserts the name never leaves the Mac. AI-23 asserts there is no whole-case analysis read without the case's stored permission.

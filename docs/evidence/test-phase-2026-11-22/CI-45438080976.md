## Causes and fixes

**Intentionally changed behaviour — AI-47 (owner 2026-11-23).** This was the first CI run with the AI-agent split. AI-47
retired the rule answer composers and gates (`RetiredPaths.ruleAnswerComposers`): with AI off, Ask answers with search
results and composes nothing.
- The two ledger suites test the retired rule path (the absent-person refusal, the named-document focus). They now
  turn it back on for their own tests only with the `.ruleAnswering` trait, as the other rule-path suites already do.
  Marked "Updated for AI-47". The trait is per task; nothing changes for the app.
- JobOutcomeMatrix: the nine `*.ask` jobs now return "2 case row(s), 1 with sources" (search results) instead of
  "1 case row(s), 0 with sources". The matrix is a measurement, so it was regenerated from the test's own output.

**Timeouts (no hang).**
- Test step: 6,788 tests. build-for-testing takes about 15 minutes inside the step, and the ten batches take 8–12 minutes
  each. So about 110 minutes is needed against a 100-minute limit. Step limit 100 → 135, job limit 125 → 165.
- Release build: one whole-module swift-frontend for the app target. Successful builds had grown to 72, 73, 81, 84, 86
  and 87 minutes (runs since 2026-11-22), and this one passed 90. Job limit 90 → 120.
- Type-check check (Xcode 26.x locally, `-warn-long-expression-type-checking=200`, into /tmp/tc-dd, since deleted).
  Four expressions in files changed since be5d1563 were rewritten with explicit types:
  - ClaimSelectionService `reconcile` sort, 1,475 ms;
  - AIAssist `review` sentence chain, 511 ms;
  - SmartMapS7MoneyTests l. 113, 851 ms;
  - three test closures of 330–437 ms.

  The other expressions over 400 ms are the first use of an `AppState` member in a file (`appState.answerArchive`, the
  `AppState(...)` initialiser, 1.4–1.6 s each). That cost is AppState member lookup, not expression complexity. The
  Debug build on CI's Xcode 26 compiles them, so they were left as they are. The build ran alongside a test run, so
  the times are inflated.

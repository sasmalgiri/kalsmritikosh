*studio* — a specialist work product exists and is unit-verified, its journey not yet verified;

*gap* — the intended result is not produced yet (the job returns only generic rows).

## What each result family does when input is missing, negative, inconclusive or denied

| Family | Behaviour |
|---|---|
| intakeScope | No scope, no case: nothing is answered until sources are authorised; a source outside scope is never used. |
| caseQuestion | No supporting passage: an honest refusal naming what was searched; conflicting passages: both shown; denied source: not used. |
| methodRun | Missing inputs block the run with the missing list; an inconclusive run is saved as inconclusive, not as a finding. |
| dataAnalysis | Unreadable rows are listed, not dropped; a result over partial data says so. |
| sourceExhibitInventory | A missing or unreadable source stays listed as missing; it never counts as reviewed. |
| peopleIdentity | Ambiguous identities stay separate until a person decides; a merge is reversible. |
| chronologyLinkage | Undated items are labelled undated; disputed dates are shown both ways; a link without a source is not drawn. |
| issueEvidenceMatrix | An element or claim without evidence shows as unsupported; contrary evidence is always listed. |
| interviewsQuotes | Quotes are verbatim with their source; corrections append and never overwrite; an unanswered request is recorded as unanswered (no admission). |
| reliabilityConflicts | An unassessed source is shown as unassessed; a conflict stays open with both sides until resolved. |
| hypothesesCausation | A cause or hypothesis without evidence stays a hypothesis; an inconclusive analysis is saved as inconclusive. |
| monetaryWorkpapers | Unreadable amounts and unstated currencies block totals; unexplained differences are differences, not loss or fraud. |
| researchCitation | Nil searches are recorded with coverage; a citation missing metadata is flagged; absence proves nothing beyond the coverage searched. |
| controlledDisclosure | Anything not positively cleared is withheld; a protected item never appears in the output; a failed check blocks the package. |
| findingsPublicationProof | A finding without its required evidence or response opportunity is blocked; an inconclusive result is reported as inconclusive. |
| actionEffectivenessClosure | Actions close only by a person with a note; an ineffective action reopens its finding; closure is reversible by reopening. |
| personalRecordsBinder | Old or expired items are flagged, not dropped; nothing sensitive is included in a pack unless chosen. |

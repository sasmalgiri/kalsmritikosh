# Confidence — one presentation, documented thresholds (RC-8)

Every answer shows ONE confidence number (0–100%), computed by the
calibrated confidence engine and rendered in the quality strip. The same
number, everywhere — no second scale exists.

| Shown | Range | Meaning (plain) |
|-------|-------|-----------------|
| High | ≥ 70% | Multiple independent sources agree; direct evidence cited. |
| Moderate | 40–69% | Evidence supports it, but thinner: fewer sources or indirect wording. |
| Low | < 40% | Weak or partial evidence — read the citations before relying on it. |
| Refused | — | The archive does not answer this; the app says so instead of guessing. |

Laws behind the number:
- A verbatim quote floor answer carries the quote's own authority (cited).
- Conflicting evidence NEVER averages away — it renders as a conflict with
  both sources, and confidence reflects the disagreement.
- Salience and corroboration nudge confidence by small, bounded amounts
  (±2 points); no single signal can manufacture certainty.
- The badge ("Independent AI reading agreed") is advisory and never changes
  the number.

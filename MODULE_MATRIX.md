## How to add one

1. add a `case` to `KnowledgeModule` with title / detail / group;
2. gate the code path with `KnowledgeModuleFlags.isEnabled(.yourCase)`;
3. it auto-appears in Settings → Modules and in this matrix.


Gate ONCE, as low as possible. The Phase-1 failure recorder is gated inside
`DerivationFailureRepository.record` rather than at its twelve call sites, so
the switch cannot be honoured in some paths and forgotten in others.


## What must NOT become a switch

A correctness fix is not a module. The entity-insert cascade (P1.1) is gated
by `strictDerivation`, but BOTH of its states are non-corrupting — the switch
chooses HOW to degrade (abort the file, or skip only the dependent step),
never whether to write wrong data. Offering the old swallow-and-continue
behaviour as an option would be offering ledger corruption as a preference.

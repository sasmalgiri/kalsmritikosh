the test fails when this file differs from a fresh measurement, and prints the new text.

**Claimed** is what the parser registry declares. **Measured** is what a real parse of that
format's fixture recovered: a format keeps FULL only when its fixture parses with the expected
status, the planted fact survives, every substantive block has an exact locator, and block
order is contiguous. A claim the fixture does not bear out reads UNVERIFIED. Fixtures are
synthetic and small; they prove the parser reads the format's structure, not that every
real-world variant of it parses. English is the only language measured (see SUPPORTED_SOURCES.md).
